# VALERI — Атлас волос

Статический образовательный сайт студии VALERI: интерактивная модель волоса, повреждения, процедуры и домашний уход.

## Запуск

Все файлы сайта находятся в `dist/`. Сборка не требуется. Для локального просмотра: `python3 -m http.server 8080 --directory dist`.

Публикуйте содержимое `dist/`, сохраняя относительные пути. Исходный сайт студии: https://valerihairstudio.ru/ .

## Данные

Сайт не собирает и не хранит данные клиентов. При загрузке удаляется устаревший локальный черновик памятки (`valeri-aftercare-v2`), если он остался в браузере от прошлых версий.

## Технологии

HTML, CSS, JavaScript modules, Three.js и Canvas. Геометрия рассчитывается в module Worker; при недоступности Worker используется локальный резервный расчёт. Пояснения доступны при недоступности WebGL.

## Проверки и ограничения

Проверены синтаксис всех JS-модулей, запуск приложения с моделью DOM, навигация, карточки процедур, экскурсия и вычисление геометрии. Эти проверки не заменяют проверку интерфейса в Safari/Chrome на iOS/Android.

Three.js распространяется по MIT; исходное уведомление сохранено в `dist/vendor/three.module.js`.
