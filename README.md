# VALERI — Атлас волос

Статический образовательный сайт студии VALERI: интерактивная модель волоса, повреждения, процедуры, домашний уход и памятка клиенту в PNG.

## Запуск

Все файлы сайта находятся в `dist/`. Сборка не требуется. Для локального просмотра: `python3 -m http.server 8080 --directory dist`.

На хостинге нужен HTTPS для системной отправки файлов и копирования изображений. Публикуйте содержимое `dist/`, сохраняя относительные пути. Исходный сайт студии: https://valerihairstudio.ru/ .

## Памятка на телефоне

Заполните форму, нажмите «Поделиться изображением» и затем «Отправить с телефона». PNG создаётся заранее; системное меню вызывается отдельным нажатием. Для многостраничной памятки доступны отправка всех страниц и каждой страницы отдельно. Если браузер или приложение не поддерживает передачу файла, скачайте PNG либо откройте картинку и сохраните её долгим нажатием.

Кнопки веб-мессенджеров открывают переписку, но не прикрепляют файл автоматически. Пользователь выбирает получателя и подтверждает отправку.

## Данные

Поля памятки обрабатываются только в браузере. Черновик сохраняется локально только по кнопке «Сохранить черновик» и удаляется кнопкой «Очистить». Серверного хранения клиентских данных нет.

## Технологии

HTML, CSS, JavaScript modules, Three.js и Canvas. Геометрия рассчитывается в module Worker; при недоступности Worker используется локальный резервный расчёт. Пояснения доступны при недоступности WebGL.

## Проверки и ограничения

Проверены синтаксис всех JS-модулей, запуск приложения с моделью DOM, навигация, карточки процедур, экскурсия, сохранение/очистка памятки, PNG-пагинация, сценарии передачи файлов/буфера обмена и вычисление геометрии. Эти проверки не заменяют проверку интерфейса в Safari/Chrome и реальную отправку на iOS/Android.

Three.js распространяется по MIT; исходное уведомление сохранено в `dist/vendor/three.module.js`.
